# Airline Passenger Satisfaction Predictor

Full-stack ML app: scikit-learn model, Flask API, Angular frontend, GitHub Actions CI and GitHub Pages deployment.

## Run locally
1. Backend: `python backend\app.py` (http://127.0.0.1:5000)
2. Frontend: `cd frontend` then `ng serve --proxy-config proxy.conf.json` (http://localhost:4200)

GitHub Pages hosts the static Angular interface only; predictions run locally.
